1. MENYIAPKAN HALAMAN
Pada praktikum ini, mahasiswa diminta untuk menggabungkan tiga file HTML dari tugas sebelumnya ke dalam satu folder proyek. Struktur kode yang telah dibuat tetap dipertahankan dengan baik. Selain itu, judul pada setiap halaman diperbarui agar sesuai dengan isi halaman masing-masing.

2. NAVIGASI KONSISTEN
Pada tahap ini, mahasiswa menerapkan susunan navigasi yang sama pada seluruh halaman website. Atribut aria-current disesuaikan dengan halaman yang sedang dibuka. Setelah itu, setiap halaman diperiksa untuk memastikan semua tautan navigasi dapat digunakan dengan benar.

3. PATH DAN ASET
Pada bagian ini, mahasiswa memeriksa kemungkinan kesalahan pemanggilan file melalui Developer Tools, terutama error 404. Penulisan path pada HTML dan CSS juga dicocokkan dengan nama file yang sebenarnya, termasuk penggunaan huruf besar dan kecil. Langkah ini dilakukan agar gambar, stylesheet, dan aset lainnya dapat ditampilkan tanpa masalah.
