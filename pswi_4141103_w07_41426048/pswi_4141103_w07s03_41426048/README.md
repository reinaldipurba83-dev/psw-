1. Repository Aman
Pada praktikum ini, mahasiswa mempelajari cara mengelola proyek menggunakan Git dengan memanfaatkan branch agar perubahan kode dapat dikerjakan secara terpisah tanpa mengganggu kode utama. Perintah git status digunakan untuk melihat kondisi file yang sedang dikerjakan. Jika file belum masuk ke staging area, pengguna dapat menjalankan git add . untuk menyiapkannya sebelum commit. Selanjutnya, git branch digunakan untuk melihat daftar branch yang tersedia, sedangkan git switch nama-branch berfungsi untuk berpindah ke branch yang diinginkan. Dengan langkah tersebut, proses pengembangan kode menjadi lebih teratur dan riwayat perubahan dapat tersimpan dengan baik.


2. Simulasi Review
Pada bagian ini, mahasiswa mempelajari proses pemeriksaan kode atau code review untuk memastikan perubahan yang dibuat sudah sesuai dengan kebutuhan. Proses ini dilakukan dengan membandingkan kode sebelum dan sesudah diperbarui, kemudian memberikan saran atau masukan melalui dokumen review. Jika ditemukan kesalahan atau bagian yang perlu ditingkatkan, mahasiswa melakukan perbaikan berdasarkan hasil pemeriksaan tersebut. Kegiatan ini bertujuan untuk meningkatkan kualitas kode serta melatih kerja sama dalam pengembangan perangkat lunak.


3. Menggabungkan Perubahan
Praktikum ini membahas cara menyatukan hasil pekerjaan dari branch fitur ke branch utama. Langkah pertama dilakukan dengan kembali ke branch utama menggunakan perintah git switch nama-branch-utama. Setelah itu, perintah git merge nama-branch-fitur digunakan untuk menggabungkan perubahan dari branch fitur ke branch utama. Untuk memeriksa hasil penggabungan dan melihat riwayat perubahan terbaru, mahasiswa dapat menggunakan perintah git log --oneline --max-count=5. Melalui tahapan ini, mahasiswa dapat memahami proses penggabungan kode dengan tetap mempertahankan riwayat commit sehingga pengembangan proyek lebih mudah dipantau.


4. WALKTHROUGH KESIAPAN UTS
   - Semantik pada web merujuk pada penggunaan elemen HTML yang memiliki arti atau makna yang jelas, baik bagi pengguna, browser, maupun mesin pencari. HTML semantik memanfaatkan tag khusus seperti `<header>`, `<nav>`, `<article>`, `<section>`, dan `<footer>` yang secara spesifik mendeskripsikan peran serta fungsi dari konten di dalamnya. Penggunaan tag semantik ini sangat penting karena membantu mesin pencari memahami struktur situs web untuk keperluan, sekaligus meningkatkan aksesibilitas bagi perangkat pembaca layar dalam membantu pengguna berkebutuhan khusus menavigasi halaman web.
   - form merupakan Elemen HTML yang digunakan untuk mengumpulkan input atau data dari pengguna, seperti teks, kata sandi, pilihan dropdown, atau checkbox, yang nantinya dapat dikirimkan ke server untuk diproses.
   - CSS merupakan Bahasa pemrograman yang digunakan untuk mengatur tampilan dan gaya visual elemen HTML pada halaman web, seperti menentukan warna, jenis huruf, jarak, tata letak, hingga animasi.
   - LAYOUT Struktur penataan atau penyusunan posisi elemen-elemen di dalam halaman web (seperti navigasi, konten utama, dan sidebar) agar tampilan rapi serta nyaman dilihat, umumnya dibuat menggunakan teknik CSS seperti Flexbox atau CSS Grid.
   - Responsive Pendekatan desain web (Responsive Web Design) yang membuat tampilan situs web dapat menyesuaikan tata letaknya secara otomatis agar tetap rapi, fungsional, dan nyaman diakses di berbagai ukuran layar perangkat, mulai dari ponsel, tablet, hingga komputer desktop.
   - git Sistem pengontrol versi (version control system) yang berfungsi untuk mencatat setiap perubahan kode sumber pada proyek perangkat lunak, memungkinkan pembuatan cabang (branching), serta mempermudah kolaborasi antar pengembang tanpa saling menimpa pekerjaan.
